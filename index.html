Institutional Quant Architecture

Engineered for Prime Desks & FinTech Platforms

Mindrative computes real-time portfolio valuation, multi-factor risk telemetry, and domain briefings strictly from observed exchange data. Missing history fails closed with explicit error codes—no hallucinations, no synthetic extrapolation.

Deterministic Observed Valuation

Portfolio NAV, period returns, and benchmark-relative alpha in basis points (bps) are computed exclusively from verified exchange closing prices.

Cryptographically Signed Receipts

Every portfolio scan returns an HMAC-SHA256 digest and HSM-backed RSASSA-PSS signature with key fingerprint for MiFID II and SEC Rule 204-2 compliance.

Zero-Knowledge Security

API keys are verified via high-entropy SHA-256 digests. Portfolios execute entirely in volatile memory and are never persisted to long-term database storage.

Asynchronous High-Throughput Jobs

Heavy frontier optimizations or 10,000-path Monte Carlo projections accept Prefer: respond-async, returning HTTP 202 with polling job IDs.

OAuth 2.0 Short-Lived Tokens

Exchange client credentials via POST /v1/oauth/token for 15-minute bearer tokens with embedded IP allowlists and granular route scopes.

Best-Effort Idempotency

Opaque Idempotency-Key headers prevent accidental trade or scan double-executions, cached securely for up to 24 hours.

Institutional Compliance & Governance

Cryptographically Signed Audit Receipts

To eliminate trade settlement disputes and satisfy SEC Rule 204-2 and MiFID II recordkeeping standards, Mindrative signs every portfolio valuation response with HSM-backed RSASSA-PSS digital signatures.

Asymmetric Digital Signatures

Each response includes a detached signature generated using Hardware Security Modules (HSM) with standard RSASSA-PSS and SHA-256 digests.

Public Key Discovery

Clients can independently fetch the public PEM certificate and key fingerprint via GET /v1/receipts/keys to cryptographically verify responses offline.

Per-Key IP Allowlisting

Restrict production API keys and OAuth tokens to specific corporate IP addresses or VPC CIDR ranges. Forwarding headers are rejected to prevent IP spoofing.

mindrative_risk_scanner.py • Python Integration Example 
import os
import sys
import uuid
import requests

API_KEY = os.environ.get("MINDRATIVE_API_KEY", "mnd_live_your_ultra_key")
ENDPOINT = "https://api.mindrative.com/v1/portfolio/scan"

def scan_portfolio(positions, benchmark="SPY", client_reference=None):
    """
    Submits positions for deterministic close-based portfolio valuation and risk telemetry.
    Returns calculated NAV, Sharpe, Beta, VaR, holding contributions, and signed audit receipt.
    """
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
        "Idempotency-Key": f"portfolio-eval-{uuid.uuid4().hex[:12]}"
    }

    payload = {
        "benchmark": benchmark,
        "timeframe": "3M",
        "include_ai_memo": False,
        "positions": positions
    }
    if client_reference is not None:
        payload["note"] = client_reference

    resp = requests.post(ENDPOINT, json=payload, headers=headers, timeout=12)

    if resp.status_code == 400:
        err = resp.json()
        if err.get("code") == "SYMBOL_LIMIT_EXCEEDED":
            print(f"[!] Quota Exceeded: Max allowed symbols is {err.get('max_allowed_symbols')}")
        sys.exit(1)

    resp.raise_for_status()
    return resp.json()

if __name__ == "__main__":
    my_positions = [
        {"symbol": "NVDA", "shares": 50, "weight": 40.0},
        {"symbol": "AAPL", "shares": 40, "weight": 30.0},
        {"symbol": "MSFT", "shares": 30, "weight": 30.0}
    ]

    print("Executing quantitative scan via Mindrative Engine...")
    result = scan_portfolio(my_positions, benchmark="QQQ", client_reference="Q3 Alpha Strategy")

    scan = result["scan"]
    summary = scan["summary"]
    print(f"Portfolio NAV:      ${summary['nav']:,.2f}")
    print(f"Period Return (3M): {summary['period_return_pct']:+.2f}%")
    print(f"Alpha vs QQQ:       {summary['vs_benchmark_bps']:+} bps")
    print(f"Portfolio Beta:     {summary['beta']:.2f}")
    print(f"Sharpe Ratio:       {summary['annualized_sharpe']:.2f}")
    print(f"Daily 95% VaR:      {summary['daily_var_95_pct']:.2f}%")
    print(f"Receipt Key ID:     {result.get('receipt', {}).get('key_id')}")
